Retrieval: Bringing Learning Back — updated prototype

Files:
- index.html — course structure/content (14 slides)
- style.css — responsive GBS styling
- module.js — interactions, navigation and light-touch SCORM analytics
- scorm_api.js — SCORM 1.2 wrapper
- Retrieval-Planning-Template.docx — editable downloadable planning template

For GitHub Pages, upload all files to the same folder and open index.html.
For an LMS/SCORM package, these files can be incorporated into the final SCORM 1.2 package/manifest.

The course does not gate navigation or set a pass/fail score. Formal assessment is intended to take place separately in the VLE.
